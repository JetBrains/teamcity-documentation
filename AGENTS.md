# TeamCity Documentation Repository

## Purpose
- Source for the TeamCity Help site.
- Writerside project configuration lives in `writerside.cfg`.

## Key Paths
- `topics/`: Main documentation topics (authoring happens here).
- `images/`: Image assets referenced by topics.
- `writerside.cfg`: Writerside project settings and instances.
- `*.tree`: Navigation trees for TeamCity and TeamCity Cloud.
- `v.list`, `c.list`, `g.list`, `labels.list`: Variables, categories, tags, and labels.

## Notes for Changes
- Prefer editing topics in `topics/` and keep cross-references consistent.
- Update lists (`v.list`, `c.list`, `g.list`) when adding new variables, categories, or tags.
- Images should live in `images/` and be referenced with stable names.
